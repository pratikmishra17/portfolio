# Pratik Mishra - Software Developer Portfolio

Welcome to the source code for my personal portfolio website. This project is a responsive, single-page application built with React to showcase my skills, projects, and professional experience as a software developer.

### [View Live Demo](https://pratikmishra.vercel.app/)

---
## About This Project

This portfolio was built to be a clean, modern, and fully responsive hub for my professional work. It serves as an interactive resume, providing an overview of my capabilities in software development, my completed projects, and how to get in touch with me.

---

## Technology Stack

This project was built using a modern frontend technology stack:

-   **[React](https://reactjs.org/):** A powerful JavaScript library for building user interfaces.
-   **[Tailwind CSS](https://tailwindcss.com/):** A utility-first CSS framework for rapid, custom UI development.
-   **[React-Icons](https://react-icons.github.io/react-icons/):** A library providing a vast collection of popular icons.
-   **[GitHub Pages](https://pages.github.com/):** For easy and reliable deployment.

---

## Key Features

-   **Fully Responsive Design:** Adapts seamlessly to all screen sizes, from mobile phones to desktop monitors.
-   **Component-Based Architecture:** The UI is broken down into reusable React components for maintainability and scalability (e.g., `Navbar`, `Hero`, `Projects`, `Skills`, `Contact`).
-   **Interactive UI:** Smooth scrolling and hover effects to create an engaging user experience.
-   **Dynamic Project Showcase:** A dedicated section to display my key projects with links to their code and live demos.
-   **Skills Section:** A visual representation of my technical skills and competencies.
-   **Contact Form:** A functional contact section to facilitate communication.

## How to Run This Project Locally

To get a local copy up and running, follow these simple steps.

### Prerequisites

You'll need to have [Node.js](https://nodejs.org/en/) and `npm` (which comes with Node.js) installed on your machine.

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/pratikmishra17/portfolio.git](https://github.com/pratikmishra17/portfolio.git)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd portfolio
    ```
3.  **Install NPM packages:**
    ```bash
    npm install
    ```
4.  **Run the application:**
    ```bash
    npm start
    ```
This will run the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will reload automatically if you make edits.
